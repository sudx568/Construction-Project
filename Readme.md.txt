# AI Construction ERP & Marketplace

An advanced B2B platform designed to streamline construction material procurement through AI-driven insights and a robust supplier marketplace.

## 🚀 Key Features

* **Verified Marketplace:** Discover materials from top-tier suppliers like ACC and UltraTech.
* **Smart Filtering:** Search by product name, category, or specific supplier.
* **Order Management:** Detailed product specifications, including ratings, stock status, and minimum order quantities.
* **AI Insights:** Dedicated module for data-driven construction analytics.
* **Comprehensive Dashboard:** Centralized hub for managing orders and project progress.
* **Secure Payments:** Integrated payment portal for seamless bulk transactions.

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Hosting:** Vercel

## 📁 Project Structure

* `/app`: Main application routes and pages.
* `/components`: Reusable UI elements (Product cards, Filters, Navigation).
* `/hooks`: Custom React hooks for state and data fetching.
* `/public`: Static assets (images, icons).
* `/styles`: Global CSS and Tailwind configurations.
